What it does

Overview

The user logs in with their own VRoid Hub account. The app shows the license of each character and loads only the characters whose conditions of use allow the intended use. Visual effects (post-processing) are applied to the loaded character inside the app.

How characters are used

Rules

Each character is used only within the conditions set by its creator on VRoid Hub. No character is re-uploaded, shared outside the app, sold as a standalone asset, or used to train AI. The author's credit is shown wherever a license requires it.
